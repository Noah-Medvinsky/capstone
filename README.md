# Capstone Portfolio

CSS 497 capstone portfolio for Noah Medvinsky, published with GitHub Pages at
https://noah-medvinsky.github.io/capstone/

The project code lives in
[ctcf-pwm-vs-hyenadna](https://github.com/Noah-Medvinsky/ctcf-pwm-vs-hyenadna).

## Editing

- Page text: the `.md` files (`index.md` is the Capstone landing page).
- Navigation: `_data/nav.yml`. Developer's Perspective themes are listed there in reading order.
- Layout and styles: `_layouts/default.html` and `assets/css/style.css`.

Local preview (needs Ruby and Jekyll): `jekyll serve`, then open http://localhost:4000/capstone/
